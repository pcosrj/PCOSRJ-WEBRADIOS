# Q Bradeira Black & SoulCast Web Rádio — Player

Player de rádio online, publicado gratuitamente via GitHub Pages.

## Estações
- Q Bradeira Black
- SoulCast Web Rádio

## Como publicar este site (GitHub Pages)

1. Crie um repositório novo no GitHub (pode ser público, é obrigatório ser
   público se você estiver no plano gratuito pessoal).
2. Suba o arquivo `index.html` desta pasta para a raiz do repositório.
3. Vá em **Settings → Pages** (barra lateral esquerda).
4. Em "Build and deployment" → "Source", selecione **Deploy from a branch**.
5. Em "Branch", selecione `main` (ou `master`) e a pasta `/ (root)`. Clique em **Save**.
6. Aguarde 1–2 minutos. O link do site aparece no topo dessa mesma página,
   no formato:
   `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

Pronto — o player fica no ar, gratuito, com HTTPS automático (necessário
para os streams tocarem sem bloqueio do navegador).

## Atualizar o site depois

Qualquer alteração no `index.html` (trocar estação, redes sociais, etc.) —
é só subir o arquivo atualizado de novo pro mesmo repositório, substituindo
o anterior. O GitHub Pages republica sozinho em cerca de 1 minuto.

## Domínio próprio (opcional)

Se você tiver um domínio (ex: `radioqbradeira.com.br`), dá pra apontar ele
pro GitHub Pages gratuitamente também, em **Settings → Pages → Custom domain**.
